This is a personal blog. It sets no cookies and shows no ads.

**Hosting.** The site is served by GitHub Pages (GitHub, Inc.). Like every web server, GitHub may log the IP address and the requested page for operational purposes. See GitHub's [privacy statement](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement).

**Page views.** To see which posts get read, the site loads a small script from [GoatCounter](https://www.goatcounter.com). It counts page views, the referring site, and coarse browser and country information. It uses no cookies, stores no IP addresses, and builds no profiles. You can block it with any content blocker; the site works without it.

**Contact.** If you have a question about this site, write to the address in the [imprint](/imprint/).

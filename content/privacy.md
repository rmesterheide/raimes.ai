This is a private blog. It sets no cookies, shows no ads and loads no third-party scripts. Visitor statistics come from anonymised server logs and a page-view counter that stores nothing but a number per day, see below.

**Controller.** Raiko Mesterheide, Zur Lutternschen Egge 65, 32549 Bad Oeynhausen, Germany. Contact: see the [imprint](/imprint/).

**Hosting and server logs.** The site is served from Hetzner Online GmbH, Nuremberg, Germany, under a data processing agreement. Like every web server, it writes a log line per request: the requested page, time, status, the referring page and your browser's user agent. Your IP address is anonymised by the web server before it is written (the last part of the address is replaced), so the logs cannot be traced back to you. The server deletes its logs after seven days; I keep anonymised copies for the statistics below. Legal basis: legitimate interest in operating a reliable website, Art. 6 (1) (f) GDPR.

**Statistics.** I use these anonymised logs to see which posts are read, where readers come from and roughly from which countries. The analysis runs locally on my own machine, builds no profiles, uses no cookies and shares nothing with third parties.

**Page-view counter.** Each page also runs a small script of my own that sends one signal ("a page was viewed") to this server, which adds 1 to a counter for the current day. The counter stores nothing else: no cookie, no IP address, no referring page, no browser details, no time of day, so it cannot tell visitors apart or recognise anyone. The result is one number per day, which I show on a display at home. The script runs on this server only; no third party is involved. Legal basis: legitimate interest in knowing whether the site is read, Art. 6 (1) (f) GDPR.

**No tracking.** No third-party analytics or counters, no fonts from third parties, no embedded videos or social media widgets. Links to other sites are plain links.

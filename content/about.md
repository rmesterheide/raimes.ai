I'm Raiko. By day I work in IT, by night I run a homelab with a Mac mini as
control center and an RTX 4090 workstation for local models.

This site is where I document what I learn about:

- **Claude Code** as a daily tool: workflows, skills, memory, the things that
  went wrong and how I fixed them.
- **Private AI**: running models at home, when it is worth it and when it is not.
- **Homelab plumbing**: the unglamorous parts that make the rest work.

Everything here is written in English so it is useful to as many people as
possible. The site is built with [Hugo](https://gohugo.io) and hosted on
GitHub Pages. The source is on
[GitHub](https://github.com/rmesterheide/raimes.ai).

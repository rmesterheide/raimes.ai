I'm Raiko. By day I work in IT, by night I run a homelab with a Mac mini as
control center and an RTX 4090 workstation for local models.

This site is where I document what I learn about:

- **Claude Code** as a daily tool: workflows, skills, memory, the things that
  went wrong and how I fixed them.
- **Private AI**: running models at home, when it is worth it and when it is not.
- **Homelab plumbing**: the unglamorous parts that make the rest work.

Everything here is written in English so it is useful to as many people as
possible. The site is built with [Hugo](https://gohugo.io) and the [PaperMod](https://github.com/adityatelange/hugo-PaperMod) theme and hosted on
a Hetzner web hosting package in Nuremberg, Germany. The source is on
[GitHub](https://github.com/rmesterheide/raimes.ai).

## How this site is written

Every post here is written with Claude Code, and this is how the work is split.

I decide, the agent builds, I check. I pick the topics, run the measurements, give the talks and hold the opinions. The drafts start from my notes: speaker notes, lab logs, benchmark results, the project notes I keep next to the code. Claude Code turns those into a first version of the text. I read every draft, cut what does not earn its place, correct what is wrong and publish only what I would say myself. Mistakes are mine.

Numbers come from my own measurements or from a named public source. Where a number depends on the setup, the post says so, including the hardware it was measured on. When I find an error after publishing, I correct it in the post with a date, not silently.

Posts written this way carry a short note at the end that links here. I keep the note because this site is about working with Claude Code, and the site itself is part of the evidence. If you want to know how the sausage is made: the drafting rules, the editorial plan and the project notes are in the [repository](https://github.com/rmesterheide/raimes.ai).

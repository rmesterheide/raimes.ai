# raimes.ai

Personal blog, Hugo + PaperMod, hosted on Hetzner Webhosting L since 2026-10-17 (GitHub Pages before). Posts are English.

## Hosting (2026-10-17, moved from GitHub Pages to Hetzner Webhosting L)
- Why: GitHub Pages gives no access logs; Hetzner writes daily access logs with IPs anonymised by the web server (last IPv4 octet / last 88 IPv6 bits), kept 7 days, so visitor statistics work without any script or cookie. Research report: `../reports/Blog Hosting mit Besucherstatistik.md`.
- Package: Hetzner Webhosting L (8.32 EUR net/month; Raiko chose L over S on 2026-10-17, it adds SSH, Node.js and Redis) plus raimes.ai as external domain (0.64 EUR net/month). SSH on port 222 still answered "Permission denied (publickey)" on 2026-10-17 although SFTP on port 22 works with the same key; deploy and log pull therefore use SFTP. If SSH is wanted later (rsync, GoAccess on the host), check in konsoleH whether SSH must be enabled for the account first. konsoleH account server `www795.your-server.de`, main FTP user `ekui5y`, web root `public_html/`, logs in `www_logs/raimes.ai/`. SFTP on port 22 with key auth (Mini key and the deploy key `~/.ssh/raimes-hetzner-deploy` are registered in konsoleH under Settings > Login data > Public SFTP Keys). No passwords in this repo.
- Deploy: `.github/workflows/deploy-hetzner.yaml` builds with Hugo and mirrors `public/` to `public_html/` with lftp over SFTP on every push to `main`. Repo secrets: `HETZNER_SFTP_HOST`, `HETZNER_SFTP_USER`, `HETZNER_SSH_KEY`. The old Pages workflow and `static/CNAME` were removed on 2026-10-17.
- Apache rules in `static/.htaccess`: 404 page, HTTPS and bare-domain redirect (www -> apex), ACME path exempt, cache lifetimes.
- DNS at GoDaddy since 2026-10-17: `@` A 167.235.125.76, `@` AAAA 2a01:4f8:1061:2275::2, `www` CNAME raimes.ai. The four GitHub A records are gone. `raimes.de` still redirects via the Pages repo rmesterheide/raimes-de-redirect (unchanged).
- TLS: Let's Encrypt certificate for raimes.ai + www.raimes.ai issued 2026-10-17 (valid to 2027-01-15, auto-renewed by Hetzner). konsoleH path: open the domain raimes.ai (not the hosting account) > Einstellungen > SSL Manager; "Neues Zertifikat" > Let's Encrypt with the www box ticked, then under SSL-Accounts pick the certificate and click the refresh icon. Verified: HTTPS 200 on IPv4 and IPv6, www and http redirect to https://raimes.ai/.
- Statistics: `scripts/fetch-logs.sh` pulls `www_logs/raimes.ai/` with lftp into `~/raimes-logs/raw`, feeds each file once into a persistent GoAccess database and writes the report to `~/claude-projects/_vorschau/raimes-stats/index.html`, served at http://macmini01.local:8787/raimes-stats/. LaunchAgent `../homelab/mac-mini/launchagents/de.raimes.raimes-stats.plist` (daily 05:30, before the 06:00 morning report; registered in `mini-dienste.sh`). The morning report gets a "Blog" section from `../mini-ops/bin/blog-status.py`, which reads the same raw logs (pages only, bots dropped, yesterday plus seven-day trend) and prints UNKLAR while no log file exists. `../mini-ops/bin/site-check.sh` adds reachability, certificate days left (PRUEFEN under 20) and the www redirect to the same section. Log format assumed Apache combined; verify on the first real file (`LOG_FORMAT=...` override). Hetzner's own AWStats/Report Magic are in konsoleH under Statistics.
- Privacy page and About updated for Hetzner, anonymised logs and local statistics; the US-transfer paragraph is gone.

## Conventions
- Editorial plan and post backlog: `EDITORIAL.md`. One post per week at most, drafts stay `draft: true` until Raiko says publish.
- Timed publishing: `scripts/publish-post.sh <slug> [label]` sets `draft: false`, moves the date to now, commits, pushes and checks the live URL (log `~/Library/Logs/publish-post.log` on the Mini). One-shot timer plist `../homelab/mac-mini/launchagents/de.raimes.publish-once.plist` (edit slug and date, install with launchctl bootstrap; it removes itself after the run). Armed 2026-10-15 for the GPU architecture post at 2026-10-16 09:00.
- Disclosure (2026-10-15, Raiko approved the wording): every post drafted with Claude sets `written_with_claude: true`; `layouts/_partials/extend_post_content.html` renders the note, `extend_head.html` styles it, the long version is on `/about/#how-this-site-is-written`. New posts get the field from day one.
- Posts go in `content/posts/<slug>.md`, front matter per `archetypes/posts.md`.
- Abbreviations (rule from Raiko, 2026-10-16): every product abbreviation is spelled out on first use in each post before the short form appears: "VMware Cloud Foundation (VCF)", "vSphere Kubernetes Service (VKS)", "Private AI Services (PAIS)". This includes titles, summaries and covers: there, prefer the long form or avoid the abbreviation. Check every draft for capital-letter acronyms before handing it over.
- Keep `draft: true` until Raiko says publish.
- Preview: a Hugo server with drafts runs permanently on the Mini (LaunchAgent `de.raimes.hugo-raimes`, see `../homelab/mac-mini/README.md`). Open `http://macmini01.local:1313/posts/<slug>/` in the MacBook browser; never give `localhost` links, Raiko reads the app on the MacBook. Still run `hugo -D` for a build check before pushing; every push to `main` deploys.
- Theme is a git submodule in `themes/PaperMod`; do not edit files there,
  override via `layouts/` instead.
- Design refresh 2026-10-15 (pushed the same evening, Raiko approved on the preview): Inter self-hosted in `static/fonts/`, teal accent and styles in `layouts/_partials/extend_head.html`, favicon set in `static/`, default social image `static/images/og-default.jpg`, typographic covers in `static/images/covers/` (made from SVG with qlmanage, cropped and converted with sips), covers on all posts with `cover.hiddenInSingle: true`, new home text and footer line in `hugo.yaml`. New posts: add `cover.image` and `cover.alt`; typographic cards are generated from SVG (see git history of `static/images/covers/`).
- Topic groups (2026-10-16): every post carries exactly one `categories` value, `homelab-ai` or `vmware` (term pages with title and description in `content/categories/<slug>/_index.md`, overview at `/categories/` as "Topics" in the menu). `layouts/_partials/post_meta.html` overrides PaperMod's partial and prepends a small uppercase label with a dot before date, reading time and author; list cards get a 3 px left border via `:has()`. Colors are OKLCH siblings (same lightness and chroma, rotated hue): `--topic-homelab-ai` teal `#1f6f78` light / `#6cc3c9` dark (the site accent), `--topic-vmware` aubergine `#76557e` light / `#cba2d4` dark, all in `extend_head.html`. Covers carry the same hue: `scripts/make-cover.py <slug> <topic> "<title>" "<subtitle>"` renders the 1200x630 typographic cover in the topic gradient (headless Chrome + sips), teal for Homelab & AI, aubergine for VMware. Posts without a category (hello-again) show no label. Tags stay as they are and do not separate the groups.
